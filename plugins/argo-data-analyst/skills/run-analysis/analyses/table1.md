# table1 — ready

A Table 1: every variable in the set described once for each level of a grouping
variable, and once overall. Continuous variables get n, missing, mean, sd, median,
q1, q3. Categorical variables get n and pct for each level, plus missing — and the
percentage is out of the **applicable** denominator (records where the field's
branching logic actually fires), not out of the whole cohort.

## What it needs from the user

1. **The grouping variable — REQUIRED, and asked once, explicitly.**
   There is no default and there will never be one. "By site" and "by district"
   are different tables, and a session that guessed produced a plausible, wrong
   one that nobody caught. Ask for it by name, in one question, naming the
   candidates you can see in the data dictionary — "group by `site` (the data
   access group) or by `district`?" — and write the answer into `README.md`
   before any script is generated. Pass it to `scaffold.py` as `--group-by`.
2. **The variables to include — optional.** Defaults to the **demographics form**:
   the first form in the data dictionary whose name contains `demograph` (or the
   first form if none does), minus the record-ID field, the grouping variable, and
   anything a table can't summarise (free text, notes, dates, uploads). `scaffold.py`
   resolves that default when the folder is made and writes the result into the
   script as an explicit `VARIABLES` list — a table should say what it counted, and
   the analyst should be able to edit the list without reading the library. Override
   with `scaffold.py --variables age,sex,education` or by editing the list.
3. **P-values — off unless asked.** No test is run unless the user asks for one.
   When they do: chi-square (Fisher for small cells) for categorical, Welch's t or
   Mann-Whitney for continuous, and any Monte Carlo step is seeded so the number
   is the same next run.

## What it produces

| File | What it is |
|---|---|
| `outputs/tables/table1.xlsx` | One workbook. Sheet `Table 1` is the table; the final `Notes` sheet carries N, the missing-data rule, the applicable-denominator rule, the generating script and the date. |
| `outputs/figures/<field>_by_<group>.png` | PNG, 300 dpi, colourblind-safe, title = the field's label, subtitle = `n = … ; missing = …`. The script that made it is its provenance. The generated script charts the first variable that has levels to draw (`FIGURE_FIELD`); swap in any other. |

Levels appear in **codebook order** — the order the choice list has in the data
dictionary — never alphabetical.

## The lib calls a study script makes

Python (`scripts/01_table1.py`, generated by `scaffold.py --group-by`):

```python
from argo_analysis.core import load_study, apply_missing
from argo_analysis.table1 import table1
from argo_analysis.excel import write_workbook
from argo_analysis.figures import bar_by_group

study = apply_missing(load_study("data/export.csv", "data/data_dictionary.csv"))
tbl = table1(study, group_by="site", variables=["age", "sex", "education"])
write_workbook({"Table 1": tbl}, "outputs/tables/table1.xlsx", notes=["..."])
bar_by_group(study, "sex", "site", "outputs/figures/sex_by_site.png")
```

R (`scripts/01_table1.R`, the same calls, the same output shape):

```r
for (f in c("core", "table1", "excel", "figures"))
  source(file.path("lib", "R", "argo_analysis", paste0(f, ".R")))

study <- apply_missing(load_study("data/export.csv", "data/data_dictionary.csv"))
tbl   <- table1(study, group_by = "site", variables = c("age", "sex", "education"))
write_workbook(list("Table 1" = tbl), "outputs/tables/table1.xlsx", notes = c("..."))
bar_by_group(study, "sex", "site", "outputs/figures/sex_by_site.png")
```

Optional arguments: `variables` (a list of field names — pass it; the scaffolded
script always does) and p-values, which are **off** unless asked for — spelled
`p_values=True` in Python and `pvalues = TRUE` in R.

The statistics live in the library, tested once against a golden table. A study
script is a list of lib calls — it never re-derives a mean, a percentage or a
denominator of its own.
